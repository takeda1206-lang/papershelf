Papershelf 説明書

PRIVATE STUDY SHELF — MANUAL

← アプリを開く（書架へ）

Papershelf は、勉強用のHTMLファイルを一か所に収蔵して iPhone と Mac の両方から読み、 付箋とメモを貼っておける、あなた専用の書架です。 この説明書は、新しい端末を追加するときの手順（GitHubトークンの作り方）と、 日々の使い方・よくある質問をまとめたものです。

一仕組み — どこに何が保存されるか

アプリ本体は「器」だけで、あなたのファイルは入っていません。 蔵書（HTMLファイル）と付箋はすべて、あなたの GitHub アカウントの 非公開リポジトリに保存されます。どの端末から見ても同じ一つのデータを 読み書きするので、常に同じ書架が見えます。

アプリのURL（全端末共通・ブックマーク推奨）
https://takeda1206-lang.github.io/papershelf/
安心 付箋はアプリの管理ファイル（shelf.json）にだけ記録されます。 収蔵したHTMLファイル自体は1文字も変更されません。

二新しい端末を追加する（トークンの作り方）

新しい端末（買い替えたMac・iPhone、職場のPCなど）でも、アプリのURLを開いて 「鍵」＝アクセストークンを一度設定すれば、同じ書架がそのまま見えます。 トークンは端末ごとに新しく作るのがおすすめです （以前のトークンは一度しか表示されないため、再利用より新規作成が簡単。 古い端末はそのまま使い続けられます）。

  1. GitHub のトークン作成ページを開く github.com/settings/personal-access-tokens/new を開き、takeda1206-lang でログインする。
  2. 名前と有効期限
    • Token name: Papershelf-iPhone のように端末名を入れると後で区別しやすい
    • Resource owner: takeda1206-lang のまま
    • Expiration: Custom で最長（約1年後）を選ぶ
  3. Repository access — 対象を1つに絞る Only select repositories を選び、 Select repositories から papershelf-data だけを選択する。
  4. Permissions — ここが一番つまずきやすい
    • Add permissions を押すと権限の一覧が出る
    • 検索欄に Contents と入力（一覧はアルファベット順で、そのままだと上の方に隠れている）
    • Contents にチェックを入れる
    • 表に追加された Contents の行で、アクセスレベルを Read-only から Read and write に変更（初期値のままだと保存できないので注意）
    • Metadata が自動で Read-only として付くが、これは必須項目なのでそのままでよい
    • Pages・Pull requests・Secret scanning など他の項目は一切チェック不要
  5. 生成してコピー Generate token を押し、表示された github_pat_… をコピーする。 この画面を閉じると二度と表示されないので、その場でコピーすること。
  6. アプリに貼り付ける 新しい端末で アプリ を開き、トークン欄に貼って 接続する。ユーザー名とリポジトリ名は入力済みのはず （空なら ユーザー名 takeda1206-lang・リポジトリ papershelf-data）。
注意 トークンは合鍵と同じです。人に見せたり、メール等に残したままにしないでください。 端末をなくした場合などは トークン一覧ページ から該当のものだけ削除（Revoke）すれば、その端末からは読めなくなります。

iPhone をアプリらしく使う

Safari でアプリを開き、共有ボタン →「ホーム画面に追加」を選ぶと、 深緑の本棚アイコンが並び、全画面のアプリとして起動できるようになります。

三毎日の使い方

収蔵する
（Macのみ）		 書架画面の点線の枠に、勉強用HTMLファイルをドラッグ＆ドロップ （複数まとめて可）。枠をクリックしてファイル選択でもよい。 同名ファイルは上書き確認が出て、付箋は引き継がれる。 iPhone ではこの枠は表示されない（閲覧・削除・付箋のみ）。
読む カードをタップすると本文が開く。文中のリンクは新しいタブで開くので、 書架の画面は失われない。
付箋を貼る 右上の付箋ボタン（のアイコン）を押してから、 本文の好きな場所をタップ。色（黄・青磁・桜・空）を選び、メモを書いて 完了。メモは空でもよい。
付箋を見る・編集 本文上の付箋をタップすると編集。右上の一覧ボタンで付箋一覧を開き、 タップすると該当箇所へジャンプする。はがすで削除。
削除する 書架カードのゴミ箱、または閲覧中の右上のゴミ箱から。確認画面が出る。 Mac・iPhone どちらからでも削除できる。
探す 書架上部の「書架を検索」でタイトルを絞り込み。並びは収蔵日の新しい順。
同期 別の端末で貼った付箋や収蔵は、アプリの画面に戻ってきたときに自動で反映される。 反映されないときは再読み込みすればよい。

四よくある質問

「トークンが無効です」「読み込みに失敗」と出るようになった

トークンの有効期限切れが最も多い原因です（作成から約1年）。 第二章の手順で新しいトークンを作り、 書架右上の歯車（接続設定）から貼り直せば、データはそのまま全部戻ります。

Permissions で何を選べばいいか分からない

必要なのは Contents = Read and write の1つだけです。 Add permissions の検索欄に「Contents」と入力してチェックし、 追加された行のアクセスレベルを Read-only から Read and write に 変更してください。Metadata（Read-only）は自動で付く必須項目なのでそのまま。 他には何もチェックしません。

間違って蔵書を削除してしまった。戻せる？

アプリの画面からは戻せませんが、データは GitHub 上で履歴管理されているため、 実は過去の版がすべて残っています。papershelf-data リポジトリの履歴 （Commits）から削除前のファイルを開いて取り出せます。 難しければ、Mac の Claude Code に「Papershelf で消した◯◯を履歴から復元して」と 頼めば復元できます。

付箋の位置が Mac と iPhone で少しずれる

付箋は「どの要素のどのあたりか」を基準に貼られるため、画面幅が変わって 文章が折り返されても概ね同じ内容の場所に付きます。ただし行単位の厳密な 位置までは保証されません。ピンポイントで残したい内容はメモ欄に書いておくのが確実です。

どんなHTMLファイルでも収蔵できる？容量の目安は？

翻訳HTML・要約HTMLのような単一ファイル（画像埋め込み含む）はそのまま収蔵できます。 1冊あたり数MB程度までが快適です。冊数は数百冊規模まで実用上問題ありません。

他人に見られない？

蔵書と付箋が入る papershelf-data は非公開リポジトリで、あなたのトークンを 設定した端末からしか読めません。アプリのURL自体は誰でも開けますが、 見えるのは空の接続画面だけで、データには一切アクセスできません。 トークンは各端末のブラウザ内にのみ保存され、外部には送られません （通信先は GitHub のみ）。

ブラウザの履歴・キャッシュを消したらどうなる？

その端末の「サイトデータ」まで消すとトークン設定が消え、接続画面に戻ります。 蔵書と付箋は GitHub 側にあるので無事です。新しいトークンを作って 貼り直せば元通りになります。

お試し用の画面はある？

URLの末尾に ?demo=1 を付けて開くとデモモードになります。 ダミーの蔵書で操作を試せて、何をしても保存されません。
