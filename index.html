PRIVATE STUDY SHELF

勉強用HTMLの書架です。蔵書と付箋はあなたの非公開リポジトリに保存され、 iPhone と Mac で同じものが見えます。初回のみ、この端末にトークンを設定してください。

トークンの作り方（初回のみ・約2分）
  1. GitHub の Fine-grained token 作成ページを開く
  2. Token name に「Papershelf」、Expiration は最長を選択
  3. Repository access で「Only select repositories」→ データリポジトリ（papershelf-data）だけを選ぶ
  4. Permissions → Repository permissions → Contents: Read and write にする
  5. 「Generate token」を押し、表示されたトークンをここに貼り付ける

トークンはこの端末のブラウザ内にのみ保存されます。端末ごとに新しいトークンを作って構いません。
